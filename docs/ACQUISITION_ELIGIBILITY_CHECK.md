# Acquisition eligibility check — 2026-10-04

Scope: bounded documentation audit of Wine Quality (186) and MAGIC (159), using the existing hash-pinned UCI metadata and current official pages. No raw observations or per-row labels were downloaded, inspected or scored; no training occurred. Published documentation includes aggregate label descriptions. This does not close the acquisition data gate.

**Wine Quality: conditional development candidate.** [UCI 186](https://archive.ics.uci.edu/dataset/186/wine+quality) currently states CC BY 4.0; retain creator attribution and dataset DOI 10.24432/C56S3T. It contains red and white Vinho Verde datasets with 11 physicochemical inputs and a sensory quality target. The page lists both `winequality-red.csv` and `winequality-white.csv`, despite reporting 4,898 instances; do not treat that number as a verified combined count.

The released schema supplies no producer, bottle/batch, repeated-measurement or assessor identifiers. UCI explicitly omits contextual details such as brand and grape type. Consequently, independence across producers/batches and repeat measurements cannot be established. Color is a domain attribute, not an independent family. No declared input is the sensory target itself, but metadata cannot rule out duplicates or hidden proxies; exclude quality and any target-derived fields from predictors. Chemical measurements could motivate acquisition decisions, but the reviewed documentation supplies no assay price, latency or separable measurement-cost evidence. Shared-assay grouping also remains unverified. Only explicitly simulated costs are defensible.

**MAGIC: reserve for simulated feature-reveal development.** [UCI 159](https://archive.ics.uci.edu/dataset/159/magic+gamma+telescope) currently states CC BY 4.0; cite R. Bock and DOI 10.24432/C52C8B. Its 19,020 events and ten inputs come from Monte Carlo simulations; these are not newly acquired telescope observations. Inputs describe a common shower image, so buying individual columns does not establish independent physical measurement savings. The documentation provides neither empirical acquisition costs nor simulation-run/shower identity keys suitable for proving group independence.

The target is gamma versus hadron. Image orientation (`fAlpha`) is intentionally discriminative under the source geometry; it deserves sensitivity analysis rather than an unsupported declaration of leakage. No documented input is the class field, but proxy absence remains unverified. UCI warns that simulated class prevalence differs from real observations and recommends ROC comparisons at low background acceptance; raw accuracy cannot justify deployment utility.

**Download/version boundary.** Stored official API metadata identifies [Wine CSV](https://archive.ics.uci.edu/static/public/186/data.csv) and [MAGIC CSV](https://archive.ics.uci.edu/static/public/159/data.csv). Their metadata update dates are 2023-11-15 and 2023-12-19 respectively. These URLs and dates do not pin immutable raw versions. Before authorized data use, freeze file hashes, retrieval dates, subset/color choice, schema, exclusions, split/duplicate rules and simulated cost specification. The existing metadata hashes authenticate metadata only.

**Decision.** Prefer Wine Quality for a narrowly described development pilot with simulated assay costs, conditional on those checks. Neither candidate qualifies as fresh external confirmation or evidence of real acquisition savings.

**Registry identity warning.** The unchanged registry labels ID 447 “motor diagnosis,” but [UCI 447](https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems) is hydraulic-system condition monitoring. If Sensorless Drive Diagnosis was intended, its official identifier is [325](https://archive.ics.uci.edu/dataset/325/dataset+for+sensorless+drive+diagnosis). Resolve this mismatch before family selection; no substitute was added here.
