# Conditional successor: learn useful measurements and belief updates

Status: proposal only, October 4, 2026. Current experiments do not establish JMLR/NeurIPS readiness. Stop spending on equivalent corrections to already strong frozen predictors. A different problem needs its own data, baselines and evidence, not renamed results.

## Model hypothesis

Develop a small **two-step predictive-state acquisition network**. Its trainable state represents a distribution over labels given observed feature/value tokens, availability and remaining budget. A shared recurrent transition updates that state when a measurement arrives. A learned stochastic transition predictor estimates possible next predictive states before acquisition. A two-step planner chooses a first measurement by the expected value of the best affordable second measurement, including a stop action. This targets complementary measurements: two features can jointly predict the label even when either alone has negligible immediate value.

Train end-to-end on source-only reveal trajectories: supervised label loss at each observed state; stop-gradient prediction of the encoder state after an actual reveal; two-step return targets; and consistency between orders that reveal the same set. Query labels and unrevealed query values never enter inference. Teacher states using extra source features are privileged training information and must be counted. Prevent latent collapse through supervised predictive targets and verify it directly. Do not require individual examples to become monotonically more confident: contradictory measurements can correctly increase uncertainty. The learned transition and planner are the model contribution under investigation; neither recursion nor adding a JEPA-style loss alone establishes novelty.

## Prior-art gate before implementation

The initial primary-source review found substantial overlap. [EDDI (2019)](https://proceedings.mlr.press/v97/ma19c.html) learns partial-data representations and chooses acquisitions by information gain. [Discriminative CMI estimation (ICLR 2024)](https://proceedings.iclr.cc/paper_files/paper/2024/hash/9682490bedc064aba8aac1ab3f703507-Abstract-Conference.html) already supports variable budgets and unequal costs. [L2M (ICML 2026)](https://proceedings.mlr.press/v306/kobayashi26a.html) explicitly handles retrospective missingness and scarce labels across tasks through autoregressive pretraining and in-context acquisition. [Model-based active acquisition (2020)](https://arxiv.org/abs/2011.00825) already combines sequential latent representations with an acquisition policy.

These abstracts establish overlap, not a completed full-text novelty review. Read the full methods and audit released implementations before claiming that two-step belief transitions offer a distinct contribution. If the distinction reduces to familiar model-based planning or an auxiliary loss, reject or materially revise the proposal before training. Cost/availability shift and measurement synergy are hypotheses to test, not properties already demonstrated.

## Data and finite development gates

1. Establish an offline acquisition benchmark with verified revealable values, group identities and feature meanings. Naturally absent values cannot be revealed from a dataset. Masking originally observed entries is a simulated acquisition experiment and must be named accordingly. Unit costs are simulated unless real costs are sourced. Audit label proxies and measurement/outcome timing; do not claim clinical or causal deployment. Reserve entire datasets/families for evaluation before fitting; previous panels remain development.
2. Freeze one small model, parameter/pretraining-label budgets, three initializations and one finite evaluation batch. Include calibrated static prediction, random/static acquisition, discriminative CMI, feasible L2M and a parameter-matched one-step model. Give ablations identical privileged teachers and trajectory labels. Report training and acquisition inference costs separately. Compare two-step planning against an equal-inference-compute control.
3. First verify a mechanistic synergy task, including an additive no-synergy negative control. Passing a constructed task is only an implementation check. Require real-data reduction in NLL-versus-cost area against the strongest development baseline, positive across at least three prespecified datasets, and a paired dataset-level interval excluding zero across the full panel. A concrete dataset panel, minimum meaningful effect and multiplicity plan must be committed before scores. Never add seeds/datasets until significance. Separate planning, transition prediction and order-consistency ablations must identify the useful component.
4. Only after this gate, use unused external data and retained confirmation for a final scoped claim. The existing synthetic seeds may be unsuitable for this new problem; preserve them rather than pretending they confirm acquisition efficacy. Save models, prediction trajectories, splits, failures and reproduction commands.
