# MIRA-Bridge v1: frozen successor development

The completed native GPU mixture failed to establish an advantage over calibration. This successor tests a query-dependent correction instead of the previous fixed four-mask candidate bank. Its usefulness and novelty are unresolved. The implementation has 20,801 trainable parameters; its generic contextual control has 20,769, and its linear residual control has 13.

For the same observed query and the same frozen source predictor, corrected logit is `f(q) + h(q,S_target) - h(q,S_source)`. Shared field tokenization and support attention use observed values, masks, frozen probabilities and labeled-support residuals. Each potential is bounded before subtraction. Identity, reversal and additive consistency follow algebraically at a fixed observed query; they do not prove correct adaptation, mechanism identification or clinical safety. The field encoder accepts variable widths and jointly permuted columns. Column invariance does not demonstrate transfer across unrelated field semantics.

`configs/bridge_v1.json` fixes all seeds, label counts, optimization counts and thresholds. Three main trainable competitors receive the same episodes and update counts; separately trained target-only and no-query ablations receive the same budget if implemented in this version. Final-step checkpoints are evaluated; validation scores do not select architecture, stopping or development comparators. Supports and queries are independent samples from a shared latent world. Source fit, source support, target support and query RNG streams are disjoint. Synthetic query labels enter mask generation and scoring/meta-training only, never predictor inputs. Generator parameters are privileged evaluator information. Masks generated from labels are explicitly synthetic experiments, not natural-policy evidence.

There are sign-flip and nonlinear-shift cases, plus no-shift and label-independent missingness shifts. The label-independent null has MAR source and target policies, outcomes depending on two always-observed anchors, a separately fitted source predictor and distinct law-specific row identities; changing from an MNAR source to a MAR target would not be this null. Training uses 64 latent seeds with widths 6/10; validation uses four new seeds and development twelve new seeds with widths 6/10/14. Width14 is a structural extrapolation test, not an external dataset. The statistical unit is latent seed, averaging correlated widths/regimes; report 12 units, not 144 independent tasks. Small-support Platt and conditional value/mask interaction logistic models are fixed controls. Compare against every control instead of choosing the best on development labels. Source-fit nonconvergence stops the run; an unconverged support control invalidates the gate. Target-only potential bound4 matches the bridge/generic correction range4. Full native NeuMiss/NeuMISE and external confirmation are later readiness requirements.

Gate: shifted mean NLL improvement at least .003 with positive paired 95% lower bound against every simple control and the matched generic learner; each null regime's harm upper95 at most .001. Keep each regime, model, prediction and failed comparison. Source subtraction, query conditioning and independent support sampling are tested directly. No automatic architecture revision based on a single favorable development contrast; changes require a new version and fresh seed namespace. Confirmation seeds98000-98019 stay untouched until a fixed successor passes development and required native controls.

Model tests and a separately labeled tiny engineering smoke precede the scientific run. Freeze source hashes and commit the protocol before scores. The Modal run is one A10040GB container, 600-second function/60-second startup/540-second child caps, no retries or schedule; reserve $.80 including failures before dispatch. The $20 cap and $3 reproduction reserve remain binding. Provider resource reports allow tightening only two stopped, oversized failure provisions; final invoices remain unverified and $.50 per failed call remains retained. Detailed evidence is in bridge_budget_reconciliation.json.

Relevant primary work: [NeuMiss](https://arxiv.org/abs/2007.01627), [Domain Adaptation under Missingness Shift](https://proceedings.mlr.press/v206/zhou23b.html), [Robust prediction under missingness shifts](https://arxiv.org/abs/2406.16484). These support components and assumptions; subtraction identities alone are not a sufficient novelty claim. See BRIDGE_AUDIT.md for additional controls and limitations.
