# Support-conditioned site replacement: finite architecture pilot

October 6, 2026. This is a trainable architecture hypothesis, not an established novelty claim. Known ingredients: [expectation propagation](https://tminka.github.io/papers/ep/) removes a site to form a cavity; [MVAE](https://arxiv.org/abs/1802.05335) learns product-of-experts inference with missing modalities. The candidate combines labeled task context with replacement of learned sensor sites during three inference rounds. Full prior-art clearance remains unresolved. The purpose of this pilot is to test a specific architecture contrast before risking real evaluation labels.

For each sensor, retain natural parameters (tau_j, eta_j), with positive precision tau_j and eta_j=tau_j*mu_j. With unit prior precision, compute cavity precision 1+sum(k!=j) tau_k and cavity mean sum(k!=j) eta_k / precision. A shared two-layer trained network receives the sensor value, sensor identity, labeled-support moments, cavity mean/log-precision and observed-sensor fraction; it REPLACES its site. Missing sensors contribute zero. Three rounds return mean=sum eta/(1+sum tau), variance=1/(1+sum tau). No claim of exact Bayesian inference, calibrated uncertainty, convergence or elimination of indirect double counting.

Controls: same-parameter three-round full-aggregate update; same-parameter static site network with the original prior in every round; a larger ordinary masked/context MLP; support-only ridge with fixed penalty1 and leave-one-out residual variance. Neural controls receive identical source tasks, minibatches, AdamW settings, 3,000 updates and three seeds. Round counts/backprop graphs differ for static/MLP; equal updates are not equal FLOPs. Static network is not a complete reproduction of MVAE. Ridge lacks source pretraining; MLP shares it. Retain all twelve checkpoints and traces before development scoring.

New synthetic sensor problem: five sensors; y=z, z~N(0,1); sensor j measures a_j*z + b_j + .4*sin(f_j*z) + d_j*u + sigma_j*epsilon_j. Task-specific signed a_j, biases b_j, nonlinear frequencies f_j, shared-noise loadings d_j and noise scales sigma_j are sampled once per task; u and epsilon are fresh per row. Only finite support labels are supplied; no population teacher parameters enter a model. Support48 with independent20% missingness; queries48/task. Source512 tasks seed819101; development64 tasks seed819102; training seeds819001-819003. Source query masks have zero or one missing sensor; development enumerates all ten two-sensor-deletion patterns. This is synthetic mask extrapolation within the same task family, not real data or unseen-family transfer.

Support context: observed sensor means/scales, mean/std of y, per-sensor standardized cross moment with centered y, per-sensor observation rates, and pairwise standardized feature cross moments. All use support only. Query labels enter source fitting loss or final development scoring only. No old panels or protected seeds98000-98019 are opened. No HAR activity labels are read.

Primary candidate fixed: three-round cavity model at3,000 updates. Gate: mean Gaussian NLL improves by at least .01 over EACH other method on EACH training seed, and MSE is no more than1% worse than each control. Report task/seed/scenario cells, coverage, training traces and all failures; no hyperparameter search, checkpoint selection or retries. If the gate fails, close this finite batch. A pass supports a scoped architecture contrast and permits a separately frozen real-data study; it does not establish JMLR readiness or novelty. Maximum600 wall seconds per fit/evaluation command, one CPU thread, cloud0USD. Snapshot source/protocol/data hashes and commit before fitting.

Pre-fit independent review found no blocking implementation issue. Site variants have3,202 nominal parameters; MLP8,514. Static inputs disable cavity context, so active degrees of freedom differ despite nominal parameter matching. This panel alone cannot separate correlation effects from missing-pattern extrapolation; no such causal attribution will be made. Task/seed/deletion-pattern scores are retained explicitly.
