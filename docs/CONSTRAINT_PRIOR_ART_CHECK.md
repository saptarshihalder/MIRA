# Constraint-transfer acquisition: bounded prior-art check

October 4, 2026. **Verdict: no defensible architectural novelty is established for the mechanism currently specified in `FEASIBLE_SUCCESSOR_PLAN.md`.** This is a targeted primary-source review, not proof that no novel mechanism exists. No models were trained, datasets downloaded, or external outcomes scored.

| Closest primary evidence | Implication for the proposed model |
|---|---|
| [ACFlow-DFA paper](https://arxiv.org/abs/2006.07701) and [actual acquisition implementation](https://raw.githubusercontent.com/lupalab/ACFlow-DFA/master/dfa_modules/cls_dfa.py), particularly `next_candidates`, `_next`, and `__call__` | Learned arbitrary conditional distributions already support simulated candidate observations. This implementation enumerates unobserved features, samples conditional values, computes average conditional information gain, and updates the mask for a bounded number of steps. A learned transition model plus masked acquisition is established; this inspected selector is myopic, so it alone does not anticipate the entire proposed planner. |
| [MEASURES, TPM 2023](https://starling-lab.github.io/assets/pdfs/Athresh_TPM2023.pdf), Algorithms 1–2 and Theorems 1–2 | Probabilistic circuits already support acquisition through classifier moments. A critical qualification: classifier variance is tractable under the stated circuit compatibility conditions, but expected variance is #P-hard and approximated by conditional sampling. Replacing a flow with a circuit does not establish novel acquisition or make arbitrary multi-step planning exact. |
| [SFOLS, ICML 2022](https://proceedings.mlr.press/v162/alegre22a.html), with [author code](https://github.com/LucasAlegre/sfols) | Learning successor features whose policies form a convex coverage set already supports transfer across linear reward preferences. A Pareto bank of terminal risk and expected feature counts, selected by deployment prices, overlaps directly. The result concerns the shared task dynamics and action space; deleting actions is a different change. Code availability was located, not implementation-audited. |
| [SFT-CoP, ICRA 2023, author explanation](https://clear-nus.github.io/blog/sft-cop) | Constraint-aware successor transfer already exists: shared dynamics, linear reward/utility features, and Lagrangian policy transfer with target dual optimization. Its expected-utility constraints differ from pathwise acquisition feasibility, but “successor features plus constraints” cannot be claimed as the contribution. |
| [BRiG-AFA, August 2026](https://arxiv.org/html/2608.02305v1), Sections 3–4 and 7 | Budget-specific terminal-risk regression with Bellman backups is already explicit. Its reported setting has unit costs, exactly B acquisitions, and a frozen predictor; stopping and heterogeneous prices are stated extensions. Those differences describe implementation scope, not sufficient architectural novelty. |
| [AFA with Incomplete Training Data, September 2026](https://arxiv.org/html/2609.32325v1), Sections 3–5 | Restricted action sets can preserve one-step values while degrading multi-step values under MCAR. Generative restoration and learned acquisition dynamics followed by Bellman planning are already studied. Training missingness is distinct from permanent deployment unavailability: restoration must not make a forbidden deployment measurement actionable. |

The concrete distinction from an ordinary stored successor representation is that deleting an action invalidates future occupancy predictions that expected to use it. Masking only the next action does not repair that error. However, carrying the availability mask and remaining budget through every imagined state, decrementing budget, and recomputing Bellman backups is standard finite-horizon model-based planning. Predicting the resulting feature counts and training this computation end to end does not, by itself, change that conclusion.

The unresolved burden is therefore an explicit learned operator that offers something beyond ordinary masked planning under composed constraint edits—such as a proved approximation/computation advantage plus matched empirical evidence. The plan currently supplies neither that operator nor such a result. Commuting independent availability deletions is already Boolean mask algebra; enforcing it alone is not a sufficient mechanism. Do not authorize successor training on the strength of this proposal. First specify a mathematical difference and compare it against the same learned conditional model with direct masked Bellman planning at equal supervision and compute.
