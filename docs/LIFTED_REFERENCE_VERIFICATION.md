## Actionable claim corrections

1. Replace related work's “inside a fixed model” characterization with “learns operators for specified factors; here sensor response is inferred from deployment calibration support.” Heess explicitly permits operator reuse across models.
2. Keep Proposition 1 restricted to mask-independent Gaussian experts **over the scalar target**. Do not imply it rules out MVAE, multivariate PoE, or every scalar-cavity network.
3. Qualify “every missingness pattern” exactness as exact inference for each selected sensor subset under the stated fitted generative model. Informative masks can contribute additional likelihood information; NeuMiss explicitly addresses such mechanisms.
4. Preserve the existing conditional permutation guarantee and narrow rank-necessity assumptions. These source checks do not independently validate either proof.
5. Describe the proposed contribution as a candidate architectural combination and restricted necessity result requiring matched controls and trained evidence. These eight sources do not establish absence of closer prior art, general superiority, or acceptance readiness.
