# Descriptive training-seed sensitivity

Recorded October 11 while the frozen continuation is running, before any v4
endpoint contrasts were computed locally. Some score archives already exist;
this is an added descriptive audit, not untouched-data preregistration and not
a new confirmation endpoint. Models, data, three seeds, margins and all five
original decisions remain unchanged.

Only after full verification and successful bound CPU replay, compute each
paired seed's point gain for all E8–E12 comparisons, using the same task-mask
averaging and pooled equal-week aggregation as the frozen endpoints. TabPFN is
the same fixed pretrained comparator for every fitted LCT seed. Report all three
values, their minimum, maximum and sample standard deviation. No seed is removed
or designated primary, and no per-seed pass rule or confidence interval is added.

These three point contrasts describe variability across the actual fitted
source models, conditional on shared panels and the fine-tuning recipe. They do
not quantify population-level training uncertainty or supply an independent
dataset replication. Preserve the original marginal intervals and their limits.
