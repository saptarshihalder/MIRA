# Native meta-training reproduction

The native_meta_inputs artifact contains all96 source-only2024 training episodes and26 used2025 development episodes, with actual native values/masks, labels, logits and row identities. No synthetic labels or new missingness are introduced. Its raw_replay_audit records independent reconstruction from original public data and frozen CUDA-trained XGBoost3.4.1; native_meta_freeze pins prepared inputs and all model/runner sources before fitting. The adapter training/evaluation runtime is local PyTorch2.8 CPU; Python3.12/XGBoost3.4.1 was used only to prepare/replay backbones. Original model remains a trained contribution; this pilot trains new weights rather than changing the old checkpoint.

For training/evaluation, use NumPy, SciPy, scikit-learn and PyTorch CPU. Restore exact historical native baseline arrays by extracting artifacts/reports/crossfit_extension/original_native_inputs.zip into an isolated repository clone; paths are repository-relative. Do not overwrite a different existing input. All new training inputs are tracked under artifacts/reports/native_meta_inputs/. The result runner refuses to overwrite output directories. To reproduce without touching tracked results, add experiments/crossfit_v1 to Python's module path, import native_train, set native_train.OUT to a separate nonexistent absolute directory, and call native_train.main(). Source hashes still apply because the runner file remains unchanged. Run the independent native_audit.py against the saved output folder.

Full raw reconstruction additionally needs the public datasets listed in artifacts/manifests/large_native_source.json and the source_backbone.json/boundaries_and_meta.npz mirrors under artifacts/reports/large_native_a100_v3/. Original preparation paths live under ignored artifacts/runs/. All identities are public dataset row/year keys; no private patient records are introduced. Preparation runtime/version checks are distinct from the learning-method result. Used cohorts remain development. No fake dataset-independent confidence interval or acceptance/safety guarantee.
