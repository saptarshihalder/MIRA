# Support-descent spectral filter: one bounded successor

Prospective hypothesis: learn which support-error eigenmodes transfer to query prediction while constraining every adaptation step to descend a convex support objective. This is a trained architecture proposal; novelty and downstream safety are unproven. Existing JEPA diagnosis on used data found that accurate head fitting worsens predictions, so amplification of its pooled embeddings is not justified.

Use the frozen Bridgev1 generator and exactly the fresh seeds/labels in configs/spectral_v1.json. All four regimes retained. Fit source backbone separately; target support and query labels remain disjoint. Six support-only steps, fixed feature basis [1,values,masks,all value-mask products] scaled by target-support RMS. The feature basis is handcrafted, not a learned embedding. The novel-candidate component is a257-parameter shared mode-filter MLP taking curvature, target/source standardized gradient magnitudes, signed agreement, uncertainty and iteration. It outputs gates in(0,1). Source/target label information is legitimate support input; query labels appear only in meta-training loss.

Objective L(w)=mean BCE(z+A w,y)+rho||w||²/2, rho=.05. H=.25 A^T A/n+rho I is a global Hessian upper bound for logistic loss. Write H=V diag(h) V^T. Learned update w'=w-Bg with B=V diag(gate/h)V^T has 0<=B<=H^-1, hence L(w')<=L(w)-g^T B g/2 in exact arithmetic. This guarantees support-objective descent only; it does NOT guarantee test-risk improvement, distribution-shift safety, likelihood calibration or scientific novelty. An all-zero gate would reproduce frozen logits exactly, although the implemented sigmoid gate approaches zero rather than attaining it at finite weights. Eigenvector sign flips leave features/gates/update invariant; repeated-eigenvalue rotations can change the learned coordinate treatment and require future stability analysis.

Related foundations: [OptNet](https://proceedings.mlr.press/v70/amos17a.html) embeds optimization within learned networks; [MetaOptNet](https://openaccess.thecvf.com/content_CVPR_2019/html/Lee_Meta-Learning_With_Differentiable_Convex_Optimization_CVPR_2019_paper.html) learns representations through differentiable solvers. Existing learned-optimizer and spectral regularization work may subsume aspects; a direct novelty review remains required. [Supervised contrastive learning](https://arxiv.org/abs/2004.11362) motivates label-discriminative representation objectives for a later trainable nonlinear feature map; it is not implemented in this filter.
