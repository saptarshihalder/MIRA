# Frozen support-conditioned Bellman mechanism diagnostic

October 4, 2026. Implementation: `experiments/support_bellman_probe.py`. This is a small synthetic test of integrating support adaptation and delayed-value learning. No novelty, real-data, clinical, arbitrary-missingness, or unseen-function-family claim is permitted.

Preparation is separate from fitting. Run the script with `--prepare` once to create immutable source/test arrays, task parameters, configuration and hashes under `artifacts/local/support_bellman_probe_v1`. Before fitting, the root must write `artifacts/manifests/support_bellman_probe_freeze.json` mapping this script, this protocol, and every prepared file's repository-relative path to SHA256. The fit command verifies those files, refuses an existing output directory, and has no automatic retry. This authoring step has not executed preparation or training.

Data are exactly three independent uniform binary features. Each task chooses selector index j, the other two indices in ascending order, parity orientation, and label-flip noise uniformly from [.03,.2]. The label is the first other bit when selector=0 and the second when selector=1, XOR parity, followed by independent noise. Source seed 814101 creates 192 tasks; test seed 814102 creates 48. Both balance the same six selector/orientation functions. Noise parameters and independent support draws change; Boolean function families do not. These 48 tasks are not 48 independent dataset families.

Each task provides 64 labeled support rows with independent per-feature MCAR=.2. The model sees only observed support values and support labels. For each of the 27 ternary partial states, compute the number of matching rows for which every specified coordinate was observed, normalized by 64, and Laplace-smoothed positive rate (positive+1)/(count+2). These 54 statistics include no hidden coordinate, population parameter, or task identifier. The query encoder uses revealed binary values and an observation mask. All queries start empty.

Privileged source supervision is deliberate: exact task conditional label probabilities supervise a shared predictor, and exact population transitions supervise action-risk heads. This does not solve learning from incomplete source data. Held-out population parameters are opened only after all checkpoints are saved and are used exclusively for evaluation and explicitly labeled population references. No held-out query label or parameter reaches an optimizer. Source targets are conditional expected NLL of the frozen learned predictor, avoiding differences in prediction quality across learned policies.
