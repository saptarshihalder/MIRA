# Wine acquisition: frozen development benchmark

October 4, 2026. Purpose: establish whether finite-data trained beliefs and constraint-aware planning offer real-observation headroom. This is an established-model benchmark, not a novel architecture claim or external confirmation. Prior-art audit rejects novelty of masked Bellman planning alone. No repair-probe cells are reused.

Data: UCI Wine Quality red and white, 11 original physicochemical inputs; binary quality >=6. Color domains share a family. Group identical full feature vectors globally, retaining contradictory labels together. Assign groups by a deterministic hash to 60% fitting, 20% validation and 20% development. Fit feature terciles on fitting rows only. Neither producer/batch independence nor physical assay costs are known. All costs and feature-level separability are simulated. Do not treat metadata or column independence as proof of measurement independence.

Models: class-conditional mixture of 16 categorical product components per class, all 11 features discretized to three bins, 1,088 trainable parameters. Every mixture is initialized identically within seed. Joint model minimizes full-row joint negative log likelihood divided by 12. Masked-label variant additionally minimizes masked-label NLL; observed masks have independent Bernoulli rates drawn uniformly from [0,1]. Both use Adam, learning rate .01, 500 updates, batch256, seeds 813001-813003, no tuning or early selection. The probability model is normalized and can condition on arbitrary revealed sets. This is a known mixture architecture; the extra objective is an exploratory trained control, not a novel method.

Strong controls: same fitted belief with greedy one-step action choice, static nonadaptive feature-subset choice (at most two), stop without acquisition, and a masked histogram gradient-boosted classifier (100 iterations, depth3, learning rate .08, L2=1, five masks per fitting row including the full row). A single tree per seed uses identical training-label boundaries and its own recorded cost. Tree planning uses the masked-label mixture's conditional feature transitions and its own calibrated predictive entropy; it is not scored against the mixture's label belief. Include greedy and static tree controls too. Shared beliefs isolate predictor differences but do not make the tree and mixture training budgets identical. Keep this limitation explicit. The mixture and tree classifier families predict only from revealed binned values plus masks. Fixed validation temperature grid [.5,.75,1,1.5,2] calibrates terminal predictions using four fixed random masks per validation row; select validation NLL only. The generative transition model is untempered.

Policies: horizon two, stop available at every state. Dynamic planning masks unavailable and already acquired actions at every imagined step; compare model-predicted terminal predictive entropy plus total acquisition cost. It cannot inspect hidden development values. The environment reveals only the selected feature; actual development labels are used only by the final evaluator. Save per-row prediction, paid cost and chosen action path. Also save source/full-availability reference scenarios, without a no-harm guarantee.

Three fixed price vectors: all .01; all .03; .01+.01*(feature index modulo3). Four availability sets: all features; missing indices[0,1]; missing[4,5]; missing[8,9]. Twelve scenarios per domain, common rows and dependent comparisons. This is within-domain simulated cost/availability variation, not train/test evidence of a universal policy. Fit models before accessing development scores. No outcome-dependent scenario removal.

Gate: masked-label mixture with depth2 must improve average realized NLL-plus-cost by >=.005 over every named control in EACH color domain; require positive difference for each initialization. Gate is exploratory development only. Report per-domain/all-seed means and every scenario; no dataset-level confidence intervals from two related domains. Passing would justify a future distinctness and independent-data protocol, not acceptance claims. Failure closes this finite experiment. Do not change costs, bins, thresholds, objectives, masks or checkpoints to obtain a pass.

Compute: CPU only, zero cloud reservations/charges. Hard wall-clock 600 seconds for model training and policy generation with no automatic retries. Preserve partial artifacts if interrupted. Data preparation, replay auditing and serialization are separately recorded. Existing Modal provisions and protected reserve remain unchanged. Freeze code, this protocol and data manifest before fitting; preserve identities and raw-data reconstruction instructions.
